# Madushanka's Portfolio Website

A responsive personal portfolio website with a dark / neon-green visual theme.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Upload all files and the `assets` folder (if used) to the root of your `portfolio` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your public contact email.
- Replace the LinkedIn URL with your own profile URL.
- Verify project descriptions, technologies and experience are accurate.
- Add real repository/demo links to project cards when ready.

Do not add passwords, API keys, private data or confidential project information.
